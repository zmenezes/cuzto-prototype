Perguntas frequentes

Tudo que você precisa saber antes de começar.

Preciso instalar algum aplicativo?
Não. O funcionário usa apenas o WhatsApp que já tem no celular. Sem download, sem cadastro, sem treinamento. Se ele sabe enviar uma foto pelo WhatsApp, sabe usar o Cuzto.
Como o sistema lê a nota fiscal?
Quando a nota tem QR Code (NFC-e), consultamos diretamente na SEFAZ do estado. Os dados são 100% confiáveis e estruturados. Para cupons sem QR Code, usamos OCR inteligente e pedimos confirmação ao funcionário antes de registrar.
Posso configurar limites por categoria?
Sim. Categorias, limites diários ou mensais, limites por pessoa, categorias proibidas, exigência de NFC-e acima de um valor. Tudo configurável pelo painel, sem precisar de um programador. A política é versionada: se mudar uma regra, despesas antigas continuam auditáveis com a regra que vigorava na época.
O que acontece se o funcionário exceder o limite?
A despesa vai para uma fila de exceções. O funcionário recebe uma explicação pelo WhatsApp dizendo qual regra foi violada e pode pedir uma exceção. O financeiro recebe a notificação e decide aprovar ou recusar pelo painel, com um clique.
Como funciona o adiantamento?
O financeiro libera um valor via PIX ou transferência pelo painel. O saldo do funcionário é atualizado automaticamente. Cada despesa debita do saldo. O funcionário pode consultar seu saldo a qualquer momento pelo WhatsApp digitando "saldo".
Meus dados são seguros?
Sim. Cada empresa tem dados completamente isolados (multi-tenancy com Row Level Security no banco de dados). Criptografia em repouso, trilha de auditoria completa, conformidade com a LGPD. Nenhuma query, endpoint ou job pode acessar dados de outra empresa.
Posso testar antes de assinar?
Sim. Comece com o plano Starter grátis (até 3 funcionários, 30 despesas/mês). Para testar os planos pagos, ative um trial de 14 dias informando o cartão de crédito. Não gostou? Volta para o Starter automaticamente, sem perder dados.
Qual a diferença para um ERP?
O Cuzto não é um ERP. É uma ferramenta focada exclusivamente em despesas de equipes em campo, com interface via WhatsApp. ERPs são sistemas complexos, caros e genéricos. O Cuzto é simples, acessível e resolve um problema específico de forma excepcional.
